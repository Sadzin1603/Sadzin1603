### Gerenciador de Chamados

A ticket management system built to explore the structure of a real ASP.NET Core application.

It includes authentication, different user roles, ticket assignment, status management, comments and ticket history.

`C#` `ASP.NET Core` `Entity Framework Core` `SQL Server` `JWT`

[Repository](https://github.com/Sadzin1603/ChamadoManager)
