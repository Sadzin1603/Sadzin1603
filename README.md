# Featured Projects

<details open>
<summary><b> Chamado Manager</b></summary>

<br/>

Ticket management system developed to explore the architecture and business rules of a real **ASP.NET Core application**.

The system manages different types of users and the complete lifecycle of support tickets.

| Aspect | Details |
|---|---|
| **Stack** | C#, ASP.NET Core, Entity Framework Core, SQL Server, JWT |
| **Type** | Full Stack / Backend-focused |
| **Features** | Authentication, user roles, tickets, employee assignment, status management, comments and history |
| **Repository** | [Access repository](https://github.com/Sadzin1603/ChamadoManager) |

**Main features:**

- Authentication with JWT and cookies
- Role-based access control
- Ticket creation and management
- Employee assignment
- Ticket status workflow
- Comments between users
- Ticket history
- SQL Server persistence with Entity Framework Core

</details>
